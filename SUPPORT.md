# Support

SLNT is experimental, pre-1.0 software. There is no paid support channel or
guaranteed response time.

## Where to ask

- **Usage questions** — open a GitHub Discussion.
- **Bug reports** — open a GitHub issue using the bug-report template.
- **Protocol or sRFC changes** — open a GitHub Discussion first; protocol
  changes need rough consensus before implementation.
- **Security or privacy issues** — do not open a public issue. Follow
  [SECURITY.md](SECURITY.md).

## Supported versions

Only the latest `main` branch is supported. Until SLNT reaches a stable
release, fixes are not backported to old commits or deployments.

## Before asking for help

Please include:

- the component you are using (`pinboard`, `registry`, Rust SDK, TypeScript
  SDK, CLI, announcer, or indexer),
- your commit SHA or package version,
- your Solana/Anchor/Rust/Node versions,
- the command you ran and the exact error,
- whether this affects funds, unlinkability, or key recovery.

For anything involving funds, key material, or privacy guarantees, treat the
details as sensitive and use the private security process.
